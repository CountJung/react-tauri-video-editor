실행 계획

1. 기준선 고정

Preview geometry/seek/pointer history, Properties routing/merge/clamp, FFmpeg input/filter/progress edge case를 characterization test로 먼저 고정합니다.

다음 우선순위

2. 책임별 분리

기능 변경과 이동을 섞지 않고 PropertiesPanel → ffmpeg.rs → PreviewPlayer 순으로 작은 추출을 수행합니다. 각 단계에서 state owner와 IPC/event 계약을 유지합니다.

3. FSD 경계 도입

shared/entities/features/widgets/pages를 빈 폴더로 먼저 만들지 않습니다. 실제 책임을 이동한 뒤 import verifier와 임시 allowlist 제거를 CI gate로 연결합니다.

4. 배포 신뢰성

플랫폼별 sidecar 검증, Tauri bundle smoke, macOS 외장 볼륨 Cargo target preflight를 유지·보강합니다.

완료 정의

  • 작업 수용 기준과 회귀 테스트가 통과한다.
  • 프리뷰와 export가 같은 timeline 의미를 유지한다.
  • 구조/상태/command 변경이 운영 문서에 반영된다.
  • 실행하지 못한 native 검증은 이유와 함께 명시한다.
